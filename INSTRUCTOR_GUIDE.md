# Інструкції для викладачів: Налаштування GitHub Classroom

## 1. Створення Assignment

1. Перейдіть до вашої організації GitHub Classroom
2. Натисніть **"New assignment"**
3. Виберіть **"Individual assignment"**
4. Введіть назву: `C++ Functions Practice`

## 2. Налаштування Repository

1. **Template repository:** `VitaliiTn/ctp-1-task-4`
2. **Repository visibility:** Private (рекомендовано)
3. **Grant students admin permissions:** No
4. **Enable feedback pull requests:** Yes (опціонально)

## 3. Налаштування Autograding

GitHub Classroom автоматично виявить наш файл `.github/workflows/classroom.yml`.

**При створенні assignment:**
1. У секції "Add autograding tests" ви побачите повідомлення про виявлений YAML
2. **Рекомендовано:** Виберіть **"Use existing workflow"** або **"Custom YAML"**
3. Система використає наш налаштований workflow

**Якщо з'явиться помилка про permissions:**
- Переконайтесь, що repository знаходиться в тій же організації що й classroom
- Або використайте особистий репозиторій з правильними налаштуваннями доступу

**Система оцінювання (100 балів):**
- Build Project: 10 балів (збірка проекту)
- Run All Tests: 90 балів (всі функції разом)

**Тести автоматично:**
- Встановлюють dependencies (cmake, build-essential)
- Компілюють код студентів
- Запускають unit тести
- Перевіряють правильність виводу
- Призначають бали

## 4. Додаткові налаштування

### Deadline
Встановіть дедлайн для завдання в інтерфейсі GitHub Classroom.

### Starter Code Protection
Файли `src/functions.h`, `test/test.cpp`, `CMakeLists.txt` та `.github/` будуть захищені від змін студентами.

### Multiple Attempts  
Студенти можуть робити необмежену кількість спроб до дедлайну.

## 5. Моніторинг прогресу

1. **Dashboard:** Перегляд загального прогресу класу
2. **Individual repositories:** Перевірка коду конкретних студентів
3. **Actions tab:** Детальні логи автотестів
4. **Feedback:** Можливість залишати коментарі в PR

## 6. Ручна перевірка (опціонально)

Навіть з автоматичним тестуванням рекомендується:
- Перевірити стиль коду
- Оцінити ефективність алгоритмів
- Залишити конструктивні коментарі

## 7. Поширені проблеми студентів

### Код не компілюється
- Студент змінив заголовковий файл
- Синтаксичні помилки в C++
- Невідповідність сигнатур функцій

### Тести провалюються
- Неправильна логіка функцій
- Не оброблені крайні випадки
- Неправильний тип повернення

### GitHub Actions не працює
- Студент не зробив push
- Конфлікти в .github/ файлах
- Перевищено ліміт часу виконання

## 8. Налаштування балів

Якщо потрібно змінити розподіл балів:
1. Відредагуйте `.github/classroom/autograding.json`
2. Змініть значення `points` для кожного тесту
3. Оновіть template repository

## 9. Розширення завдання

Для додаткових функцій:
1. Додайте нові функції в `src/functions.h`
2. Створіть тести в `test/test.cpp`
3. Оновіть `autograding.json`
4. Документуйте в `README.md`

---

**Примітка:** Цей template готовий до використання без додаткових налаштувань. GitHub Classroom автоматично створить репозиторії для студентів з усіма необхідними файлами.
