## Завдання

Розробити набір функцій для практики створення та використання функцій у мові програмування C++. Завдання включає реалізацію трьох основних алгоритмів, що демонструють різні аспекти роботи з функціями.

### Опис завдання

1. **`factorial(int n)`** - Обчислення факторіалу числа
2. **`isPrime(int number)`** - Перевірка, чи є число простим
3. **`gcd(int a, int b)`** - Знаходження найбільшого спільного дільника

## Детальний опис функцій

### 1. Функція `factorial(int n)`

**Призначення:** Обчислює факторіал натурального числа n.

**Алгоритм:**
- Факторіал n! = 1 × 2 × 3 × ... × n
- Для n = 0 або n = 1: результат = 1
- Для від'ємних чисел: поверніть 0

**Приклади:**
```cpp
factorial(0) → 1
factorial(1) → 1
factorial(5) → 120
factorial(-3) → 0
```

### 2. Функція `isPrime(int number)`

**Призначення:** Перевіряє, чи є задане число простим.

**Алгоритм:**
- Просте число ділиться тільки на 1 і на себе
- Числа ≤ 1 не є простими
- 2 - єдине парне просте число
- Для перевірки достатньо перевірити дільники до √number

**Приклади:**
```cpp
isPrime(2) → true
isPrime(7) → true
isPrime(4) → false
isPrime(1) → false
```

### 3. Функція `gcd(int a, int b)`

**Призначення:** Знаходить найбільший спільний дільник двох чисел.

**Алгоритм Евкліда:**
- НСД(a, 0) = a
- НСД(a, b) = НСД(b, a % b)
- Працює з абсолютними значеннями чисел

**Приклади:**
```cpp
gcd(48, 18) → 6
gcd(17, 13) → 1
gcd(12, 8) → 4
```

## Можливі проблеми та їх вирішення

### Проблеми з компіляцією

**Помилка: "cmake not found" або "g++ not found"**
- **Рішення:** Встановіть відповідний компілятор та CMake
  - **Windows:** Встановіть Visual Studio Build Tools, MinGW-w64, або встановіть CMake окремо
    - MinGW можна встановити з [winlibs.com](https://winlibs.com/) або через MSYS2
  - **Ubuntu/Debian:** `sudo apt install build-essential cmake`
  - **macOS:** `brew install cmake` (потребує Homebrew)

**Помилка з MinGW: "g++: command not found"**
- **Рішення:** Додайте MinGW до системного PATH
  - Знайдіть папку bin MinGW (наприклад: `C:\mingw64\bin`)
  - Додайте її до змінної середовища PATH
  - Перезапустіть термінал

**Помилка: "No such file or directory"**
- **Рішення:** Переконайтесь, що ви знаходитесь в правильній директорії проекту
- Перевірте, що всі файли присутні після клонування репозиторію

**Проблеми з кодуванням (Windows):**
- Якщо бачите "кракозябры" в консолі, додайте в початок main():
  ```cpp
  #ifdef _WIN32
  system("chcp 65001"); // UTF-8 кодування
  #endif
  ```

### Проблеми з запуском тестів

**Помилка: "tests.exe not found"**
- **Рішення:** Переконайтесь, що збірка пройшла успішно
- На Windows файл може знаходитись в `Debug\tests.exe` або `Release\tests.exe`

**Усі тести провалюються:**
- **Це нормально!** Це означає, що ваші функції ще не реалізовані
- Реалізуйте функції в `src/functions.cpp` та запустіть тести знову

### Проблеми з Git

**Git відстежує бінарні файли:**
- **Рішення:** Переконайтесь, що файл `.gitignore` присутній в кореневій директорії
- Якщо файли вже додані до Git: `git rm --cached *.exe *.o build/`

**Помилка: "LF will be replaced by CRLF" (Windows):**
- **Рішення:** Це попередження можна ігнорувати або налаштувати:
  ```bash
  git config core.autocrlf true
  ```

## Налаштування відладки (Debug) у VS Code

### Готові конфігурації

У цьому репозиторії можуть бути створені файли налаштувань для VS Code:
- **`.vscode/launch.json`** - конфігурація відладчика
- **`.vscode/tasks.json`** - задачі для збірки та запуску тестів
- **`.vscode/settings.json`** - налаштування проекту

### Швидкий старт відладки

1. **Відкрийте проект** у VS Code
2. **Поставте breakpoint** - клікніть ліворуч від номера рядка у вашому коді
3. **Натисніть F5** - проект автоматично зберется та запуститься у режимі відладки

### Правильні місця для breakpoints

#### ✅ Правильно - у ваших функціях:
- **У файлі `src/functions.cpp`** - у ваших реалізованих функціях
- **Наприклад:** всередині циклів у функції `factorial`
- **Наприклад:** в умовних конструкціях у функції `isPrime`

#### ✅ Правильно - у тестах перед викликом:
- **У файлі `test/test.cpp`** - на рядках де викликаються ваші функції
- **Наприклад:** `ASSERT(factorial(5) == 120);`
